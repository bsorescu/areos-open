# Tone-of-Voice Calibration by Segment

Pick the row matching the diagnostic's segment; calibrate every artifact
against it. When two rows apply (e.g. premium devtool), the more restrained
row wins on risk-adjacent copy.

| Segment | Register | Humor | Urgency/scarcity | Discounts | Proof style |
|---|---|---|---|---|---|
| **B2B compliance/regulated** | Sober, precise, audit-proof (see b2b-compliance.md) | Off in risk copy; trace only in low-stakes UI | Real regulatory dates only | Restraint; value justification over price cuts | Authority acceptance, named cases, exact numbers |
| **Consumer (B2C)** | Warm, plain-language, age-13 reading level | Yes — empty states, emails, 404s | Real deadlines and stock only; no dark patterns | Effective; use Rule of 100 + base-value framing | Volume social proof, individual stories |
| **Devtool** | Peer-to-peer, technically exact, zero marketing-speak | Dry wit works; never in docs/errors that block work | Almost none — devs distrust it; changelog cadence is the urgency | Transparent, usage-based; discounts read as weakness | Benchmarks, code samples, public roadmap, OSS presence |
| **Premium** | Confident, spare, few words | Rare, understated | None — scarcity is implicit in positioning | Never discount; Red Sneakers applies (with credibility) | Craft/effort shown, provenance, selective clients |
| **Early-stage SaaS** | Honest about stage, energetic, founder voice | Light; self-aware beats polished | Real capacity limits OK ("onboarding 5 pilots this month" — if true) | Pilot pricing OK if framed as stage, not desperation | Exact pilot numbers, founder access, build-in-public artifacts |

Cross-cutting rule: tone never overrides guardrails — a segment that
"tolerates hype" still gets zero unsourced claims.
