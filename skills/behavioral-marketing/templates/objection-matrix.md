# Objection handling matrix — {product/campaign}

One row per objection surfaced in the diagnostic. Every response needs proof
from the research doc — an unproven counter-claim is a new liability, not
an answer. Unanswerable objections are recorded honestly and routed to
product, not papered over with copy.

| # | Objection (buyer's words) | Segment | Real or misconception? | Response strategy | Proof (research doc ref) | Where it's handled (artifact/section) |

| 2 | | | | | | |

## Placement rules

- Product-aware audiences: objections handled prominently (FAQ, comparison
  table, pricing page) — they're actively looking for reasons to say no.
- Earlier awareness levels: don't import objections the buyer doesn't have
  yet; handle only what the diagnostic surfaced for that segment.
- The top objection gets handled twice: once implicitly in the hero proof,
  once explicitly near the CTA.
