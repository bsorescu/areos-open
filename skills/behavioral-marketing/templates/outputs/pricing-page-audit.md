# Playbook — Pricing Page (build or audit)

Prereqs: diagnostic + verified pricing facts in research-marketing.md.
Audits use _audit-format.md per element. Metrics: metrics-map.md (view →
checkout start; guardrail: refunds, billing tickets).

## Structure

- **Tier architecture:** 3–4 tiers, target tier mid-positioned (Extremeness
  Aversion); most expensive first; decoy only if honest (a real, inferior
  option — not a fake one).
- **Per-tier:** who it's for (one line), price with honest unit framing
  (per-building/per-seat), 3–5 differentiating features (not full matrix).
- **Price display:** Rule of 100 for discounts; annual = "2 months free"
  (Base Value Neglect); temporal reframing ("€0.63/day") only where credible;
  **RO/EU: VAT display rules + Omnibus 30-day anchor (localization-ro-eu.md)**.
- **Justification:** a "because" line under the tiers (Fairness) backed by
  real effort/cost facts.
- **Objections:** billing-specific rows from objection-matrix.md near the
  CTA (cancel policy, what happens at limit, upgrade/downgrade path).
- **Reassurance:** Freedom of Choice phrasing on the CTA ("cancel anytime" —
  only if cancellation is actually easy; otherwise fix the product first).

## Element checklist

Tier names/order/highlight, price framing per tier, the "because" line,
feature-list scannability, FAQ/objections, CTA copy, currency/VAT display.

## Frequent dark patterns to hunt in audits

Hidden VAT, fake anchor prices, "most popular" on a tier no one buys,
auto-renew buried, downgrade friction, decoy tiers that don't really exist.

Close with scorecard + experiment-backlog entries.
