# Playbook — Landing / Product Page (build or audit)

Prereqs: diagnostic done (research-marketing.md); audits use _audit-format.md
for every element below.

## Message hierarchy model (landing/product pages)

| Zone | Carries | Rule |
|---|---|---|
| Above fold: headline | Primary message, in the buyer's awareness register | One message. Problem-aware traffic → name the pain; solution-aware → the differentiated claim |
| Above fold: subhead | The mechanism ("how") + for whom | Concrete, no adjectives doing the work |
| Above fold: CTA + micro-trust | Desired action + friction removal ("no card", exact setup time — if true) | One primary CTA; secondary is a link, not a button |
| Section 2 | Proof for the primary message | Strongest proof from claim-verification hierarchy, placed BEFORE more claims |
| Sections 3–4 | Supporting messages, one per section, each with adjacent proof | Order = message hierarchy from marketing-plan.md |
| Section 5 | Objection handling | Top objections from objection-matrix.md; FAQ format works |
| Final CTA | Primary message restated + real deadline if one exists | Peak-end: this is the ending — earn it, don't beg |

## Element checklist (audit each with Before/Problems/After/Rationale/Test)

- Headline, subhead, primary CTA (+ its micro-trust line)
- Hero visual (does it show the product or decorate the page?)
- Proof section (sourced? specific? near the claim it backs?)
- Each supporting section's message + proof pairing
- Objection/FAQ section vs objection-matrix.md coverage
- Final CTA section (peak-end, real urgency only)
- Reading level (aim 13–14), scannability, mobile above-fold

## Biases that usually earn their place here

Concreteness, Precision, Framing (verified losses), Generation Effect
(calculator/quiz for problem-aware traffic), Fairness ("because" pricing
line), Make It Easy. Check contraindications before each.

Close with the scorecard (_audit-format.md) + experiment-backlog entries.
